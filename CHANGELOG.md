# Changelog

## [1.0.0] - 2026-06-08
### Added
- Initial SmartForm app release
- Card-based multi-step form navigation
- 5 built-in templates: housing fund, e-commerce, loan, visa, school registration
- OCR ID card recognition using Apple Vision framework
- Smart prefill engine from user profile
- Auto-save with 0.5s debounce
- Field validation (required, idCard, phone, email, length)
- User profile with secure storage
- History view for saved sessions
